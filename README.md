## 🧱 Stack do projeto

- **HTML5** semântico
- **CSS3** — custom properties, grid, flexbox, animações
- **SVG inline** — gráfico do mapa de carreira
- **JavaScript** vanilla — navegação entre páginas do PDI, scroll progress, botão voltar ao topo
- **Google Fonts** — Space Grotesk, Inter, IBM Plex Mono

Sem build, sem framework, sem dependência externa. Zero fricção para abrir e editar.
